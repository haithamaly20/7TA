# خطة الموجهين — PWA

## الملفات
- index.html: التطبيق المعدل
- manifest.json: تعريف PWA
- sw.js: Service Worker للتشغيل دون إنترنت
- icons/: أيقونات التثبيت

## المزايا المضافة
1. تصدير الخطة العامة إلى XLSX حقيقي متعدد الأوراق:
   - الخطة العامة
   - الموجهون
   - المعاهد
2. تصدير PDF من خلال نافذة الطباعة الرسمية للمتصفح، مع اختيار Save as PDF.
3. تبويب مستقل لإدارة وتعديل الموجهين والمعاهد.
4. تلوين الخلايا الفارغة في الخطة بلون تحذيري.
5. PWA قابلة للتثبيت وتشغيل البيانات المحلية دون إنترنت.
6. لا توجد مكتبات خارجية مطلوبة، حتى يظل التطبيق قابلاً للعمل دون اتصال.
7. وظائف Google Sheets تظل مرتبطة بالإنترنت فقط، بينما بيانات التطبيق المحلية والخطط المحفوظة تعمل دون اتصال.

## التشغيل
يجب استضافة المجلد على HTTPS (مثل GitHub Pages أو أي Web Server). لا يعمل Service Worker من file://.
